# Commercial Capability Research

## 1. Bloomberg Terminal / ASKB

### Capabilities
- **ASKB**: Conversational AI interface (beta Feb 2026), agentic AI with multi-agent coordination
- Multi-decade map of complex market relationships and interconnected data
- Unified structured + unstructured data (market data, news, research, documents)
- 5,000+ daily news stories, 1,200 sell-side research providers, 800+ independent research
- BQL (Bloomberg Query Language) code generation for Excel/BQuant
- Workflows: multi-step research automation, scheduled execution, firm-wide sharing
- ASKB + PORT: portfolio query, risk analysis, position analysis
- ASKB + RMS Enterprise: research note upload, AI-assisted thesis refinement
- ASKB + ALTD: alternative data synthesis, credit card signals, nowcasting
- ASKB + Expert Intelligence: Third Bridge integration, 100K+ expert transcripts
- AI Search across hundreds of millions of documents
- Document Workspace: multi-document comparative analysis
- Company Financials with AI consensus alignment
- IB chat structured intelligence
- Mobile + Apple Vision Pro access
- Transparent source attribution on every response

### Key Differentiators
- Multi-decade curated data relationships
- Firm-wide proprietary data integration
- Coordinated AI agent network
- Real-time execution integration
- 350K+ decision-maker network (IB chat)

## 3. FactSet Workstation / Intelligence

### Capabilities
- **FactSet Intelligence**: Modular AI stack for financial professionals
- AI-powered search, conversational chat
- Automated portfolio commentary (AI-generated, source-linked)
- Transcript analysis
- Agentic research workflows
- 1,100+ proprietary and third-party datasets
- **Quantitative Research**:
  - FactSet Programmatic Environment (FPE) - hosted JupyterLab
  - Quant Factor Library (QFL) - thousands of pre-calculated signals
  - Signal Selector - ML-based predictive modeling
  - Optimal Weights Engine (OWE)
  - FactSet Portfolio Optimizer (FPO)
  - 120+ risk models, 4 optimizers
  - Regime Generator/Predictor
  - Point-in-time fundamentals (eliminate look-ahead bias)
- **Portfolio Analytics**:
  - 10+ attribution models
  - Multi-asset class coverage (including fixed income, private markets)
  - Scenario analysis and stress testing
  - AI-generated portfolio commentary
  - Workflow monitoring, pre/post calculation checks
- **MCP Server**: Governed analytics access for enterprise AI
- Snowflake/Databricks integration
- Private data integration (cloud/FTP)

### Key Differentiators
- 1,100+ datasets
- 120+ risk models
- Point-in-time data for bias elimination
- MCP-native AI access layer
- Deep quant research tooling (FPE, QFL, OWE)
