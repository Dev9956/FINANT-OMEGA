## 4. PyO3 — DEFERRED

### Benchmark Results
| Operation | Time |
|---|---|
| Rust subprocess call (cargo test --release) | 317ms avg |
| Python-native portfolio calc (50 assets, 252 days) | 55us avg |
| Rust test suite (64 tests) | 0.04s |

### Decision: DEFERRED
**Reason**: No performance bottleneck. The Rust engine is called for batch operations (portfolio optimization, risk calculations) that run in seconds. The ~317ms subprocess overhead is negligible relative to network I/O (data fetch: 2-5s), LLM calls (1-3s), and database operations. PyO3 would save ~300ms per Rust call — meaningful only if the engine were called per-request (it is not).
